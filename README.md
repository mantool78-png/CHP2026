# Прогнозы ЧМ-2026

MVP сайта конкурса прогнозов к Чемпионату мира по футболу 2026. Проект рассчитан на обычный PHP/MySQL-хостинг Beget Start: без Composer, Node.js, Docker и постоянных фоновых процессов.

## Возможности

- Регистрация и вход участников.
- Ручное подтверждение взноса админом.
- Личный кабинет с прогнозами на матчи.
- Закрытие приема прогнозов за 5 минут до начала матча.
- Открытие прогнозов после старта матча.
- Ввод результатов матчей админом.
- Автоматический подсчет очков: 1 за исход, 3 за точный счет, 10 за чемпиона.
- Таблица лидеров и расчет текущего призового фонда.

## Установка локально или на Beget

1. Создайте MySQL-базу данных.
2. Импортируйте `database/schema.sql` через phpMyAdmin.
3. Скопируйте `config/config.example.php` в `config/config.php`.
4. Укажите реальные доступы к базе в `config/config.php`.
5. Загрузите файлы проекта на хостинг.
6. Убедитесь, что Apache использует `.htaccess`. Если домен можно направить прямо в папку `public`, это предпочтительный вариант.

Файл `config/config.php` содержит пароль базы и не должен попадать в GitHub.

## Деплой изменений на Beget

Ниже — типичный цикл: правки в репозитории → выкладка файлов на хостинг → быстрая проверка. Подставьте свои **логин**, **домен** и **путь к сайту** из панели Beget.

### Куда класть файлы

На виртуальном хостинге Beget сайт обычно лежит в каталоге вида:

```text
/home/ЛОГИН/ИМЯ_САЙТА/public_html/
```

Внутри `public_html` должна повторяться структура проекта: папки `app/`, `config/`, `public/`, `views/` и т.д. (как в этом репозитории). Точный путь смотрите в панели: **Сайты** → ваш домен → корневая папка.

### Что нельзя затирать без нужды

- **`config/config.php` на сервере** — там продакшен-доступы к MySQL. При выкладке из Git или архива убедитесь, что вы **не перезаписываете** этот файл пустым шаблоном.
- Для примера настроек в репозитории есть **`config/config.example.php`** — его можно обновлять свободно.

### Способ 1: FTP или файловый менеджер Beget

1. Войдите в [панель Beget](https://cp.beget.com).
2. Откройте **FTP** или **Файловый менеджер** и перейдите в корень сайта (`public_html` или аналог).
3. Загрузите **только изменённые** файлы, сохраняя пути:
   - правки в PHP/шаблонах: `app/…`, `views/…`, `public/index.php`;
   - стили и картинки: `public/assets/…`;
   - при изменении примера конфига: `config/config.example.php`.
4. Откройте сайт в браузере, при необходимости обновите страницу с принудительным сбросом кэша (Ctrl+F5).

### Способ 2: SSH и `scp` (если SSH включён для аккаунта)

С своего компьютера (PowerShell, терминал) можно копировать файлы по SSH. Пример — залить обновлённую главную и стили:

```powershell
scp D:\путь\к\CHP2026\views\home.php ЛОГИН@ИМЯ_СЕРВЕРА.beget.tech:/home/ЛОГИН/ИМЯ_САЙТА/public_html/views/home.php
scp D:\путь\к\CHP2026\public\assets\styles.css ЛОГИН@ИМЯ_СЕРВЕРА.beget.tech:/home/ЛОГИН/ИМЯ_САЙТА/public_html/public/assets/styles.css
```

Перед первым подключением убедитесь, что в панели Beget для FTP/SSH-пользователя указана **только папка нужного сайта**, а не весь аккаунт.

**Проверка PHP после выкладки:** в SSH по умолчанию может быть старая версия `php` в CLI. Для проверки синтаксиса используйте явный бинарь, например:

```bash
/usr/local/bin/php8.2 -l /home/ЛОГИН/ИМЯ_САЙТА/public_html/public/index.php
```

Веб-сервер при этом обычно отдаёт сайт на актуальной версии PHP (смотрите **PHP** в панели для домена).

### Бэкап перед крупным обновлением

Через SSH можно снять архив текущих файлов (пример):

```bash
cd /home/ЛОГИН/ИМЯ_САЙТА/public_html
tar -czf ~/backup-site-$(date +%Y%m%d).tgz app public views config
```

Резервную копию **базы** делайте отдельно в phpMyAdmin или в разделе MySQL панели Beget.

### После деплоя

- Откройте главную и пару внутренних страниц (`/rules`, `/leaderboard`).
- Проверьте, что нет белого экрана и что статика подгружается (стили, картинки в `public/assets/`).
- При изменении правил призового фонда или текстов сверьтесь с `config/config.php` на сервере (ключи `prize_pool_*` и т.д.).

## Доступ админа

После импорта схемы создается администратор:

- Email: `admin@example.com`

Это только тестовый пароль для первого входа. Сразу замените email и пароль администратора перед публичным запуском.

## Работа с матчами

Расписание загружается через админку (CSV-импорт). Результаты можно вводить вручную или подключить **API-Football** (счёт основного времени, как в правилах).

### API-Football (опционально)

1. Миграция: `php scripts/apply_migration_009.php` (или `database/migrations/009_api_football.sql` в phpMyAdmin).
2. В `config/config.php`: секция `api_football` — `enabled`, `api_key`, `cron_token`; для виджетов на `/matches` — `widgets_enabled` (ограничьте домен ключа в dashboard API-Sports).
3. Админка → **API-Football**: привязать команды → матчи → «Синхронизировать сейчас».
4. Cron на Beget каждые 3 мин: `curl -s "https://ВАШ-ДОМЕН/cron_api_football_sync.php?token=CRON_TOKEN"`.

Официальный календарь: https://www.fifa.com/en/tournaments/mens/worldcup/canadamexicousa2026/articles/match-schedule-fixtures-results-teams-stadiums

## Что добавить перед реальным запуском

- Финальную проверку дедлайна прогноза на чемпиона перед первым матчем 1/16 финала.
